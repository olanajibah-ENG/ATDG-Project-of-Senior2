2. الدخل والخرج

Methodالمسارالوظيفة

طلب الإنشاء:

{
  "project_id": "<project UUID from UPM>",
  "version_number": 2,                      // optional -> latest
  "paths": ["MyProject/utils.py"],          // optional -> all files of the version
  "levels": ["unit", "edge", "integration"] // optional -> all three
}

الرد (202):

{ "job_id": "job_7f3a91", "status": "pending", "project_id": "...", "version_number": 2 }

الخطة:

{
  "units":   [{"id": "game.py::Student.enroll", "file": "game.py", "kind": "method"}],
  "skipped": [{"path": "readme.md", "reason": "unsupported_language"}],
  "work_items_count": 42
}

الأخطاء:

الكودمتى
400 validation_errorحقل غير صحيح: نسخة أو مسار غير موجود، أو نوع غير معروف
401الطلب بدون token أو بـ token غير صالح
403المهمة تخص مستخدماً آخر
422 no_python_filesلا يوجد أي ملف Python ضمن الملفات المختارة

3. القواعد

  • المسارات تؤخذ من شجرة المشروع التي تعرضها الواجهة.
  • ملف غير Python: يُتجاوز بسبب unsupported_language والمهمة تستمر.
  • ملف بلا تحليل: المهمة تطلب تحليله وتكمل بباقي الملفات، ثم ترجع له. إذا فشل مرتين يُتجاوز بسبب analysis_failed ويرى المستخدم ذلك.
  • ممنوع أن تنتظر مهمة خلفية مهمة أخرى. الفحص يُعاد لاحقاً.
  • الوحدات: كل دالة وميثود، ومنها __init__. الدوال الخاصة (_name) تُتجاوز بسبب private.
  • معرّف الوحدة: path::Class.method.
  • المصادقة: JWT من UPM. كل مهمة يقرؤها صاحبها فقط.

أسباب التجاوز الستة: unsupported_language · analysis_failed · no_units · empty_or_abstract · body_truncated · private

6. فحص القبول

  1. طلب على مشروع فيه ملفات Python محلَّلة يرجع 202 ورقم مهمة.
  2. الخطة لملف game ترجع 14 وحدة و 0 متجاوز.
  3. ملف غير Python يظهر متجاوزاً والباقي يُخطَّط.
  4. بدون token يرجع 401، ومستخدم آخر يأخذ 403.
  5. صفر استدعاءات للنموذج اللغوي.
  6. الاختبارات الموجودة قبل الشريحة (213) ما زالت ناجحة.

7. خارج S1

النموذج اللغوي، توليد الاختبارات، الإصلاح، التشغيل المعزول، التغطية، تنزيل ZIP، اختبارات Edge و Integration، إلغاء المهمة، قائمة السجلات، وباقي تعديلات الـ graph (الـ builtins، مستويات الثقة، io_kind، التخزين المؤقت).

8. التسليمات

  • كود S1 مع اختباراته.
  • تقرير بالعربية: نتائج الاختبارات، المجموعات والحقول التي ارتبطنا بها، طريقة استدعاء المسارات الثلاثة في Postman، وقائمة المؤجَّل.
