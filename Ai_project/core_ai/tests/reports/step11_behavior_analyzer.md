# تقرير الخطوة 11: الذكاء الاصطناعي بـ Code vs Code (BehaviorAnalyzer)

**التاريخ:** 2026-11-08
**ملف الاختبارات:** [`core_ai/tests/test_behavior_analyzer.py`](../test_behavior_analyzer.py)
**البيئة:** حاوية `ai_web` (Python 3.10، tree-sitter 0.20.4)

## الهدف
التحليل الدلالي القديم بـ Code vs Code كان يبعت المخطط كله **بأسماء الدوال بس**، بطلب بكل مقارنة، فما كان يقدر يشوف إنه شغل الدالة تغيّر. بالقياس الصغير ما كشف لحاله ولا تغيير سلوكي.

بهالخطوة صار في محلّل جديد بيبعت **بس الدوال المرشّحة** من الخطوة 9، مع الكود قبل وبعد، وبيسأل: هل التغيير بيكسر يلي عم يستدعي الدالة؟

## شو تغيّر بالكود
| الملف | التغيير |
|---|---|
| `prompts/conflict_prompts.py` | سؤال جديد (`BEHAVIOR_SYSTEM` و `BEHAVIOR_PROMPT` و `BEHAVIOR_ITEM`). لكل دالة، الموديل بيعطي: ملخّص قبل وبعد، وهل في تغيير بيشوفه يلي عم يستدعيها، ونوعه من أنواع NPM، وهل بيكسر، والدليل (سطر قديم وسطر جديد منسوخين كما هم)، ودرجة الثقة. `SEMANTIC_PROMPT` القديم ما انلمس |
